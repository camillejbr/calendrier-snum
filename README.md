# L'agenda du SNUM

Calendrier d'équipe (verres, activités, sport, repas) — récupéré depuis un artefact Claude et transformé en petit projet React + Vite autonome.

## Lancer en local

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
```

Les données (profil, événements, noms connus) sont stockées dans le `localStorage` du navigateur — pas de backend.
